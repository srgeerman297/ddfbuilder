    How Shufti reads the file

    Each page is one row, followed by one row per question. Rules always sit on the page row and use questions from that same page.

    Show / Hide changes a question on the same page. Jump / Skip goes to, or leaves out, a later page.

    A rule is written Question, EQUAL, Value ;JUMP; Page. Several rules on one page are joined with ||| . This builder writes all of that for you.

    Confirmed from Shufti's own sample file: the column layout, quoting, answer type spellings, and the four actions.

    Seen in a live client form: the answer type Email, one Show or Hide rule naming several questions, and multiple-select rules that list every combination of ticked boxes. That last one suggests a multiple-select rule matches only that exact combination. This is inferred, not documented.

    Not confirmed by Shufti: which comes first when a rule mixes AND with OR, and whether a question targeted by Show starts hidden. The checks flag these so you can test them in Shufti before going live.

    Shufti's default limit is 20 questions per form. Support can raise it.
